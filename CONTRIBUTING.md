Say "I agree to the SpoolKid CLA" in your pull request. Pull requests without
it cannot be merged.

## Ground rules

- No third-party dependencies.
- Never copy code from projects under licenses that would prevent commercial
  licensing (e.g. GPL-licensed apps); implement from their public
  documentation instead.
